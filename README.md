# The Community Café menu book

Open index.html in a modern browser. No build or installation is needed.

Only the book appears on screen. Tap its right half to go forward, or its left half to go back. Drag or swipe horizontally to turn a page with your finger. Keyboard arrow keys also work.

The cover opens into two-page spreads on wide screens. Phones show one page at a time. Images appear in order: Cover.jpg, then 1.jpg through 19.jpg, then BACK-Cover.jpg. Image URLs include a version so browsers load the replacement images.

Page movement plays the preloaded page-flip-trimmed.wav paper sound in sync with the animation. The original page-flip.wav is preserved. Keep the images, HTML, CSS, JavaScript, and WAV files together.
